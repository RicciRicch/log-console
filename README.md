# Konzola (radni naziv)

Jedan ekran na kom firma koja šalje pakete vidi sve svoje pošiljke, statuse i otkupe, bez obzira na kurira. Podaci se povlače sa kurirskih API-ja, ne unose se ručno.

Cela ideja: [`Konzola za praćenje pošiljki — ideja i workflow (iz PDF-a).md`](./Konzola%20za%20pra%C4%87enje%20po%C5%A1iljki%20%E2%80%94%20ideja%20i%20workflow%20(iz%20PDF-a).md)

## Mapa dokumenata

| Fajl | Čemu služi |
| --- | --- |
| [CONTRIBUTING.md](./CONTRIBUTING.md) | Pravila za GitHub: grane, commit-ovi, PR, review |
| [CLAUDE.md](./CLAUDE.md) | Pravila za Claude Code (čita ga automatski) |
| [PRODUCT.md](./PRODUCT.md) | Kontekst proizvoda za Impeccable (dizajn) |
| `DESIGN.md` | Dizajn sistem. Pravi ga `/impeccable init`, ne piše se ručno |
| [docs/MVP.md](./docs/MVP.md) | Šta ulazi u prvu verziju, a šta ne |
| [docs/ARCHITECTURE.md](./docs/ARCHITECTURE.md) | Stack, struktura repoa, model podataka |
| [docs/TEAM.md](./docs/TEAM.md) | Ko šta radi i kako se delovi spajaju |
| [docs/WORKFLOW.md](./docs/WORKFLOW.md) | Git, rad sa Claude Code-om, rad sa Impeccable-om |

| [docs/features/](./docs/features/README.md) | Jedan fajl po feature-u + tabla sa statusima |

## Prvi koraci

1. Svako pročita `docs/MVP.md` i `docs/TEAM.md` i proveri svoju ulogu.
2. Potvrdite ili promenite odluke u `docs/DECISIONS.md`.
3. Uroš postavlja repo (F00), ostali kreću tek kad je setup gotov.
